## 📥 Clone & Switch Branch

git clone https://github.com/BOCK-CHAIN/BockDe-Fi.git
cd BockDe-Fi
git checkout web

📦 Install Dependencies
flutter pub get

▶️ Run Web Locally

flutter run -d chrome
App will run on:
http://localhost:xxxx

🏗️ Build Web Production Files

flutter build web
Output directory:
build/web
